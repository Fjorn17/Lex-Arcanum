# Life Transference

*Transferencia de vida*

| | |
| --- | --- |
| **De dónde sale** | 5e (Xanathar) |
| **Dónde iría** | Espiritismo › Vida |
| **Llena un hueco** | no |
| **Cruza un segundo umbral** | no |

## Qué hacía

El lanzador se hace daño necrótico a sí mismo para curar al doble a otra criatura a distancia.

## Por qué encaja aquí

Es el conjuro que mejor explica de golpe la frontera entre Vida y Muerte del espiritismo: las dos Ramas trabajando a la vez sobre dos cuerpos, y el precio pagado en el propio.

## Versión 5.5e

Lista para pegar en `doc/spells/srd-en.txt`, con `== Life Transference` de cabecera.

```
level: 3
school: Necromancy
casting: Action
range: 30 feet
components: V, S
duration: Instantaneous
body:
You take 4d8 Necrotic damage, which can't be reduced in any way, and one creature of your choice that you can see within range regains a number of Hit Points equal to twice the damage you took.
Using a Higher-Level Spell Slot. The damage increases by 1d8 for each spell slot level above 3.
```
