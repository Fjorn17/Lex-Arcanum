# Far Step

*Paso lejano*

| | |
| --- | --- |
| **De dónde sale** | 5e (Xanathar) |
| **Dónde iría** | Cosmología › Paso |
| **Llena un hueco** | no |
| **Cruza un segundo umbral** | no |

## Qué hacía

Teletransporte de 60 pies como acción adicional, y otra vez cada turno mientras dure la concentración.

## Por qué encaja aquí

La Estrella de Vano repetida, que es lo que el sistema llama una marca de repetición (Reglas 5.16): no dice cuántas veces, dice las que aguantes. Es el conjuro que mejor traduce esa regla.

## Versión 5.5e

Lista para pegar en `doc/spells/srd-en.txt`, con `== Far Step` de cabecera.

```
level: 5
school: Conjuration
casting: Bonus Action
range: Self
components: V
duration: Concentration, up to 1 minute
body:
You teleport up to 60 feet to an unoccupied space you can see. On each of your turns before the spell ends, you can take a Bonus Action to teleport in this way again.
```
