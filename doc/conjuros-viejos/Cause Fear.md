# Cause Fear

*Provocar miedo*

| | |
| --- | --- |
| **De dónde sale** | 5e (Xanathar) |
| **Dónde iría** | Espiritismo › Mente |
| **Llena un hueco** | no |
| **Cruza un segundo umbral** | no |

## Qué hacía

Conjuro de nivel 1 que asusta a una criatura viva; no funciona sobre construcciones ni muertos vivientes.

## Por qué encaja aquí

La Estrella de Ánimo dice que se pone un sentimiento y que no dicta actos, porque quien recibe miedo huye o ataca según quién sea. Este conjuro ya está escrito con esa incertidumbre dentro.

## Versión 5.5e

Lista para pegar en `doc/spells/srd-en.txt`, con `== Cause Fear` de cabecera.

```
level: 1
school: Necromancy
casting: Action
range: 60 feet
components: V
duration: Concentration, up to 1 minute
body:
You wake the fear of dying in one creature you can see within range. The target makes a Wisdom saving throw or has the Frightened condition for the duration. At the end of each of its turns, it repeats the save, ending the effect on itself on a success.
A creature that can't die of old age or that has Immunity to the Frightened condition is unaffected.
Using a Higher-Level Spell Slot. You can target one additional creature for each spell slot level above 1.
```
