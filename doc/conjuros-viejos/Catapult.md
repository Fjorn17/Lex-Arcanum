# Catapult

*Catapulta*

| | |
| --- | --- |
| **De dónde sale** | 5e (Xanathar) |
| **Dónde iría** | Astronomía |
| **Llena un hueco** | no |
| **Cruza un segundo umbral** | no |

## Qué hacía

Elige un objeto suelto de hasta 5 libras y lo dispara en línea recta hasta 90 pies; lo que golpee recibe daño contundente.

## Por qué encaja aquí

Empuje puro sobre un cuerpo que ya está ahí. Ni forma materia ni la transforma: la mueve. Es la lectura más literal de «la astronomía es el sistema de reparto de todo el arte» (Reglas 4.41).

## Versión 5.5e

Lista para pegar en `doc/spells/srd-en.txt`, con `== Catapult` de cabecera.

```
level: 1
school: Transmutation
casting: Action
range: 60 feet
components: S
duration: Instantaneous
body:
Choose one object weighing 1 to 5 pounds within range that isn't being worn or carried. You hurl it in a straight line up to 90 feet before it falls, stopping early if it hits something solid. If it would strike a creature, that creature makes a Dexterity saving throw. On a failed save, the object strikes it and both take 3d8 Bludgeoning damage.
Using a Higher-Level Spell Slot. The maximum weight increases by 5 pounds and the damage by 1d8 for each spell slot level above 1.
```
