# Snilloc’s Snowball Swarm

*Ventisca de bolas de nieve*

| | |
| --- | --- |
| **De dónde sale** | 5e (Xanathar) |
| **Dónde iría** | Alquimia › Bruma |
| **Llena un hueco** | no |
| **Cruza un segundo umbral** | no |

## Qué hacía

Una ráfaga de bolas de nieve estalla en una esfera de 5 pies de radio y hace daño de frío con salvación de Destreza.

## Por qué encaja aquí

Bruma tiene la Estrella de Hielo y ningún conjuro de nivel bajo que la use como proyectil. Este es el hueco.

## Versión 5.5e

Lista para pegar en `doc/spells/srd-en.txt`, con `== Snilloc’s Snowball Swarm` de cabecera.

```
level: 2
school: Evocation
casting: Action
range: 90 feet
components: V, S, M (a piece of ice)
duration: Instantaneous
body:
A flurry of ice bursts in a 5-foot-radius Sphere centered on a point you choose within range. Each creature in the Sphere makes a Dexterity saving throw, taking 3d6 Cold damage on a failed save or half as much on a success.
Using a Higher-Level Spell Slot. The damage increases by 1d6 for each spell slot level above 2.
```
