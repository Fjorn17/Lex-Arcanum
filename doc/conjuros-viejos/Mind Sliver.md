# Mind Sliver

*Esquirla mental*

| | |
| --- | --- |
| **De dónde sale** | 5e (Tasha) |
| **Dónde iría** | Espiritismo › Mente |
| **Llena un hueco** | no |
| **Cruza un segundo umbral** | no |

## Qué hacía

Truco de daño psíquico que además resta 1d4 a la siguiente salvación del objetivo.

## Por qué encaja aquí

Extenuación en miniatura: consume lo que al otro le queda para sostener algo, sin tocarle el cuerpo. Es el truco que un mentalista debería tener y el catálogo no tiene.

## Versión 5.5e

Lista para pegar en `doc/spells/srd-en.txt`, con `== Mind Sliver` de cabecera.

```
level: 0
school: Enchantment
casting: Action
range: 60 feet
components: V
duration: Instantaneous
body:
You drive a spike of thought into the mind of one creature you can see within range. The target makes an Intelligence saving throw. On a failed save, it takes 1d6 Psychic damage and subtracts 1d4 from the next saving throw it makes before the end of your next turn.
Cantrip Upgrade. The damage increases by 1d6 when you reach levels 5 (2d6), 11 (3d6), and 17 (4d6).
```
