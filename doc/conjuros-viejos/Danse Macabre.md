# Danse Macabre

*Danza macabra*

| | |
| --- | --- |
| **De dónde sale** | 5e (Xanathar) |
| **Dónde iría** | Espiritismo › Muerte |
| **Llena un hueco** | no |
| **Cruza un segundo umbral** | no |

## Qué hacía

Levanta hasta cinco cadáveres pequeños o medianos como muertos vivientes que obedecen hasta una hora.

## Por qué encaja aquí

Marcha en plural y por poco tiempo, que encaja mejor con este sistema que la versión permanente: lo que se levanta se mueve porque el Éter lo mueve, y deja de moverse cuando el astrónomo deja de alimentarlo.

## Versión 5.5e

Lista para pegar en `doc/spells/srd-en.txt`, con `== Danse Macabre` de cabecera.

```
level: 5
school: Necromancy
casting: Action
range: 60 feet
components: V, S
duration: Concentration, up to 1 hour
body:
Threads of Ether reach into up to five Small or Medium corpses you can see within range. Each rises as a Zombie or Skeleton (your choice per corpse) and acts on your turn, immediately after you.
You can issue a general command as part of the same Bonus Action you use to move them; with no command, a risen corpse only defends itself. There is nobody inside: it does not remember, and it obeys no further than what you are imposing on it in that instant.
When the spell ends, the corpses fall and do not rise again.
Using a Higher-Level Spell Slot. You animate two additional corpses for each spell slot level above 5.
```
